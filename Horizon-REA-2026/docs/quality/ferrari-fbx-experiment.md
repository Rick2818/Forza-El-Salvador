# Ferrari FBX vs GLB: isolated V32 experiment
Source: current Ferrari F430 by Ddiaz Design, CC BY 4.0 (see original LICENSE). FBX is derived from the existing GLB, not a new native FBX asset. Blender export embeds textures; FBX does not guarantee identical PBR material semantics. No production deploy, no changes to V32 recovery. Each circuit compares same source model, race conditions and existing continuity gates. A passing software-renderer run is not 60 FPS certification. Inspect four wheel pairs, material fidelity, memory, triangle counts, draw counts and screenshots; confirm on PC and Android before any adoption. V28 continuity and vehicle geometry audits and V29 opening/VFX validation must also pass before production integration.

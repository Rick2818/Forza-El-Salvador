# WebGPU migration experiment
Isolated branch; not a full race. Uses the actual current F430 and original Track visuals for Monzón/Suzaka, with a controlled scripted camera and model motion, common lighting, no full Environment, crowds, audio, traffic or Rapier simulation. The GPU queue is drained between frames to measure completed work, not display FPS or peak throughput. Compare eight backend/format/circuit cells at matched resolution and 125 wall seconds. A WebGPU fallback or unsupported custom GLSL material fails explicitly. SwiftShader/software adapter results cannot certify real-device FPS. Full migration requires TSL replacements for custom shaders (including crowd, mud and fireworks where applicable), asynchronous renderer initialization, new GPU timing/backpressure and real hardware validation. Keep existing release gates. Source F430 attribution in public/models/external-candidates/ferrari-f430-LICENSE.txt. FBX is a derived conversion, not a different vehicle.
